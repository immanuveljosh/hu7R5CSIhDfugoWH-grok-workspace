# Pulse

Local-first Android dialer with optional call recording. This repo is the companion: a clickable phone UI plus a Kotlin project you can open in Android Studio.

## Companion (this preview)

```bash
npm install
npm run dev
```

Open Settings → Auto call recording to enable recording. Place or simulate a call; files land under **Files**.

## Android app

Open `android/` in Android Studio. See `android/README.md`.
